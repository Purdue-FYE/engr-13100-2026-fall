9.3.1. PY: Logic and Modularity#

You are a junior engineer supporting two projects. A local farmer needs help determining whether an irrigation system is watering correctly, while a mission team needs to calculate the escape velocity required to leave a planet. You will develop one menu-driven Python program containing both engineering tools, analyze the organization and design of the program, and create a flowchart representing its program flow.

Required Files#

  1. Download the Python template ENGR131_Python_Template.py and save it as 9_3_1_username.py.

  2. Download the report template, complete it, and save it as 9_3_1_report_username.pdf.

  3. Create and save your program flowchart as a PDF or a PNG: 9_3_1_flowchart_username.pdf or 9_3_1_flowchart_username.png.

Quick Guide: Completing & Submitting Your Report as PDF

To complete your technical report, you must edit the provided Word template (.docx) and convert it to a PDF for final grading. Follow this simplified workflow:

  1. Edit in Word: Download and open the .docx template in Microsoft Word. Avoid editing in web previewers or Google Docs, as they will corrupt your formulas and chart formatting.

  2. Save as PDF Only When Finished: Type your answers and copy any charts or images directly into the Word document, saving your progress frequently. Once your report is 100% complete, save or export the document as a PDF. (Do not convert to PDF early, as PDFs are static and cannot be edited!) Copy charts or images into the report and keep the originals in the workbook, since Gradescope grades the workbook.

  3. Submit to Gradescope: Upload your finalized PDF and any other required deliverables to the corresponding assignment in Gradescope. Always review your uploaded files from the Gradescope confirmation screen to verify your work is complete.

Reminder

Rename your files with your Purdue username, replacing “template” in the filename. Then fill out any required information in the template such as student name, email, etc.

Task 1: A Field Engineer’s Toolkit#

Rather than developing two separate scripts, your supervisor has asked you to create a single command-line toolkit. When the program runs, it will present the user with a menu and route the user to the appropriate engineering tool based on their selection. The irrigation system check will use conditional logic to evaluate operating conditions, while the escape velocity calculator will use a sequence of engineering calculations to determine the required velocity.

Organize the program using user-defined functions so that each function performs a specific task. This modular structure will make the program easier to read, test, debug, and reuse.

Reminder

Review and reference the Python Style Guide to ensure your code follows the required formatting and documentation standards, including the use of clear and descriptive comments.

Main Function: Menu and Program Routing#

Create a main function that displays the menu, collects the user’s selection, and calls the appropriate user-defined function.

When the program runs, it should prompt the user with:

Select a tool:
  1) Irrigation System Check
  2) Escape Velocity Calculator
Enter choice (1 or 2):

Use an if-elif-else structure to route the program:

  • If the user enters 1, call the user-defined function for the irrigation system check.

  • If the user enters 2, call the user-defined function for the escape velocity calculator.

  • If the user enters any other value, display an appropriate warning message and call main() again to redisplay the menu.

The main function should manage the overall program flow. Place the detailed calculations and decision-making logic within the appropriate user-defined functions.

Irrigation System Check#

Create a user-defined function that collects information about the irrigation system, validates the inputs, and displays an operating recommendation.

User Input#

Prompt the user to enter:

  • soil moisture as a percentage from 0 to 60,

  • forecasted rain in millimeters from 0 to 50,

  • whether the system is experiencing low pressure, and

  • whether the system requires maintenance.

Use the following prompts:

Enter soil moisture (%, 0-60):
Enter forecasted rain (mm, 0-50):
Is the system experiencing low pressure? (yes/no):
Is maintenance needed? (yes/no):

Convert the soil moisture and forecasted rain inputs to float values. Format the two yes/no responses using the appropriate string methods so that differences in capitalization or extra spaces do not affect the program.

Input Validation#

Validate the inputs before evaluating the irrigation conditions.

  • If either numeric input is outside its expected range, display a warning message and use return to end the function early.

  • Convert each valid yes/no response to a Boolean value. Assign True when the response is yes and False when the response is no. If the user enters any other response, display a warning and assign False.

Escape Velocity Calculator#

Create a user-defined function that prompts the user for information about a planet and calculates its escape velocity. Organize the calculations into separate user-defined functions.

User Input#

Prompt the user to enter:

  • the planet’s average density in \(\kilogram/\meter^3\), and

  • the planet’s radius in \(\meter\).

Use the following prompts:

Enter the density of the planet (kg/m^3):
Enter the radius of the planet (m):

Convert both inputs to float values.

Calculations#

Create separate user-defined functions for each calculation. Choose clear, descriptive names for the functions and their parameters.

Task 2: Program Analysis and Flowchart#

After completing and testing your Python program, analyze its organization and create a flowchart representing the complete program flow.

Program Analysis#

Complete the analysis questions in the report template downloaded from the Required Files section. Use specific examples from your program to support your responses and use clear, professional language.

Save the completed report as 9_3_1_report_username.pdf.

Program Flowchart#

Create a flowchart representing the complete program. The flowchart must include:

  • the menu and initial user selection,

  • the program path for each menu option,

  • the major validation and decision paths used by the irrigation system check,
