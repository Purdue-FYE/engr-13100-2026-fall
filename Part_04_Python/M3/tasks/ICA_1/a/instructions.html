10.2.1. ICA: “How Many Tries?” - Guessing Game#

In this activity, you will …#

Learning Objectives#

  • PR01: Programming Standards

  • PR04: Modular Programming

  • PR05: Code Structures

  • PR06: Translate Program Descriptions

  • PR08: Debugging

Activity Instructions#

An egineering student is building a number-guessing game. The computer picks a secret number between 1 and 20, and the player keeps guessing until they get it right. we want to know: how many times will the loop run?

Part 1 — Debug#

The following python code is what the engineering students has come up with so far for the number-guessing game.

  1. Run the code or trace it by hand. What happens?

  2. Find the bug and fix it.

import random

secret = random.randint(1, 20)
guess = int(input("Guess a number between 1 and 20: "))

while guess != secret:
    print("Try again!")

print("You got it!")
Part 1 Solution

The bug: guess is never updated inside the loop, so the condition can never become False. It’s an infinite loop that just spams "Try again!".

The fix: move the input() call inside the loop so a new guess is captured on every iteration.

import random

secret = random.randint(1, 20)
guess = int(input("Guess a number between 1 and 20: "))

while guess != secret:
    print("Try again!")
    guess = int(input("Guess a number between 1 and 20: "))

print("You got it!")

Part 2 — Build#

  1. Once the code is fixed, add a counter that tracks how many guesses it took to guess the secret number, then print "You got it in X tries!" at the end.

  2. Discuss the following: could you have written this counter logic with a ‘for’ loop instead? To help you get started, review materials on for loops in the 10.1.1 PCMs: Loops in Python.

Hint

We have not covered for loops in class. The purpose of this activity is to prepare you for next class and assignments in the Python Looping Structures unit.

Part 2 Solution
import random

secret = random.randint(1, 20)
guess = int(input("Guess a number between 1 and 20: "))
tries = 1

while guess != secret:
    if guess < secret:
        print("Too low!")
    else:
        print("Too high!")
    guess = int(input("Guess a number between 1 and 20: "))
    tries += 1

print(f"You got it in {tries} tries!")

Answer: No — you’d need to know the number of guesses ahead of time to use a for loop, which is impossible here. That’s the whole point of a while loop.
