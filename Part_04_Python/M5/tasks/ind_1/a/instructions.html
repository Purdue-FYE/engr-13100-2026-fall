12.3.1. PY: Regression#

Task #1: Wabash River Health - Dissolved Oxygen Analysis#

Background#

Dissolved Oxygen (DO) is one of the most critical indicators of river health. Fish and aquatic organisms need adequate DO to survive. DO levels are strongly influenced by water temperature: warmer water holds less dissolved oxygen (an inverse relationship).

As a junior environmental engineer at the fictional Wabash River Authority, you have been given 20 water quality measurements collected over a summer monitoring campaign. For this task you will:

  • Visualize the relationship between temperature and DO

  • Build a linear regression model to predict DO from temperature

  • Evaluate your model’s performance

  • Use your model to make engineering decisions

Required Files#

  1. Download the template ENGR131_Python_Template.py and save as 12_3_1_username.py.

  2. Download the CSV file river_data.csv for analyzing the Wabash river dissolved oxygen data. Do not submit this file to Gradescope

  3. Create and save your figures as PNG files:

    • Figure 1: 12_3_1_do_temp_plot_username.png

    • Figure 2: 12_3_1_do_temp_regression_plot_username.png

  4. Download the report template, complete it, and save it as 12_3_1_report_username.pdf.

Reminder

Review and reference the Python Style Guide to create a professionally formatted code file. For example, remember to provide detailed comments throughout your code so anyone can read them and understand what your program does!

Program Requirements#

Dataset Description

You are provided with a CSV file named: river_data.csv. The dataset contains water quality measurements collected at three Wabash River monitoring sites.

Dataset Columns

Column

Description

sample_id

Unique sample identifier

site

Monitoring site (A = upstream, B = midstream, C = downstream)

temp_c

Water temperature (\(^\circ\text{C}\))

do_mg_l

Dissolved oxygen concentration (mg/L)

ph

Water pH

Required Libraries

  • numpy

  • pandas

  • matplotlib

Part 1: Load and Explore the Dataset#

  1. Import the required libraries

  2. Load the CSV file into a pandas DataFrame

  3. Display all rows in the DataFrame.

  4. Print:

    • A formatted assignment header

    • Summary statistics for:

      • temperature

      • dissolved oxygen

      • pH

See the sample output below to review formatting of program output.

Hint

Use the describe() function to generate summary statistics.

Part 2: Exploratory Scatter Plot#

Create a scatter plot showing the relationship between water temperature (x-axis) and dissolved oxygen concentration. Use a separate color and marker shape for each monitoring site. Be sure to follow the professional plotting guidelines to ensure readability.

Save Figure 1 as a PNG using the file name specified in the Required Files section.

Part 3: Linear Regression Analysis#

Fit a linear regression model to the temperature and dissolved oxygen data:

  1. Define the independent variable (x, temperature) and dependent variable (y, dissolved oxygen concentration).

  2. Use the polyfit() function to fit a linear model to the data.

  3. Compute predicted y-values for the regression model.

  4. Calculate Sum of Squared Errors (SSE), Sum of Square Total (SST), and \(r^2\) value. Equations for SSE, SST, and \(r^2\) can be found in the Linear Regression Excel materials.

  5. Display your results in the following order (see sample output) and format values to 3 decimal places.

    • Slope

    • Intercept

    • SSE

    • SST

    • \(r^2\)

Part 4: Regression Line Plot#

Plot the linear regression model on the same figure as the scatter plot. The data markers should overlay the regression line so they are visible. Ensure the plot has an informative title and a legend with labels for the data markers and regression line. The regression label should display both the model equation and \(r^2\) value.

Save Figure 2 as a PNG using the file name specified in the Required Files section.
