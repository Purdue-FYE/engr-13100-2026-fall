```{admonition} Follow these guidelines when submitting your code assignments to Gradescope:
:class: important
* **Unlimited Submissions:** You can resubmit your code as many times as you need before the assignment deadline. Only your final, active submission is graded.
* **Submit All Files:** If you need to resubmit, you must upload **all required files** for the assignment again. Gradescope allows you to drag and drop individual files or a compressed `.zip` folder.
* **Autograder Results:** After submitting, wait a few minutes for the autograder to evaluate your code. You can scroll down to view any failed test cases. 
* **Getting Help:** If you need assistance interpreting the autograder output or errors, ask your teaching team.
* **Submission Confirmation:** When your upload is successful, you will see a confirmation message on your screen and receive an automated email receipt.

For a detailed walkthrough, review the official [Gradescope Code Submission Guide](https://guides.gradescope.com/hc/en-us/articles/21865616724749-Submitting-a-Code-assignment).

```
