### Q1.2 Reflection on Data Types

In a short paragraph (3–5 sentences), explain why understanding Python data types is important when writing code. In your response, be sure to:

(a) Describe at least one problem that can happen if you use the wrong data type

(b) Give a brief example of how a data type affects the outcome of a calculation or operation

(c) Explain how paying attention to data types can help with debugging or improving your code

#### Sample Solution

    Understanding Python data types is important because different types of data behave differently when used in calculations and operations. If you use the wrong data type, you can get errors, such as trying to add a number to a string, or you may get incorrect results, like combining two numbers as text instead of adding them mathematically. For example, adding "2" + "3" results in "23" as a string, while 2 + 3 results in 5 as a number. Paying attention to data types also helps with debugging because it makes it easier to identify why a program is producing unexpected output or raising errors.
