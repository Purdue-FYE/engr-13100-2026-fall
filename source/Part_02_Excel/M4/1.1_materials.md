# PCMs: Linear Regression in Excel

These pre-class materials introduce linear regression analysis, a method engineers use to model relationships between variables and make predictions based on data. They also explain how to use Excel to calculate a best-fit linear model for a dataset. 

In engineering, modeling data with a best-fit line helps determine key system characteristics. For example, testing the displacement of a mechanical spring to determine its overall stiffness. Software tools like Excel are used to quickly evaluate data and extract system characteristics.

## Purpose of Linear Regression
Linear regression models a dependent variable based on one or more independent variables. Engineers use this analysis to:
- Identify cause-and-effect relationships.
- Measure temporal changes (changes over time).
- Make predictions using existing data.
- Find correlations within datasets.

### Example Problem: Spring Constant Analysis
A company is designing a new ballpoint pen, but the inkwell retraction mechanisms are failing quality checks. An engineer performs force and displacement tests on the springs. According to Hooke's Law ($F = kx$), the force ($F$) required to stretch or compress a spring is linearly related to the displacement ($x$). The slope of this relationship is the spring constant ($k$), representing the stiffness of the spring.

## Least-Squares Regression
Least-squares regression is a mathematical method used to determine a best-fit line for a dataset. The resulting model takes the form of a linear equation:

$$f(x) = ax + b$$

Where:
* $x$ = independent variable
* $a$ = slope
* $b$ = y-intercept

The goal of least-squares regression is to find the slope ($a$) and y-intercept ($b$) values that minimize the **sum of squared errors (SSE)** between the model's expected values and the actual collected data points.

### Sum of Squared Errors (SSE)
SSE measures how well a model matches the actual data. It is calculated by squaring the individual error terms and summing them together: 

$$SSE = \sum (y_i - f(x_i))^2$$

Where:
* $y_i$ = the actual, measured dependent variable data point
* $f(x_i)$ = the expected value predicted by the model line

The errors are the difference between the actual data and our best guess of a model. These errors have **nothing to do with the accuracy or precision of the measurement** of either of the variables or the collection of the data.

Once a best-fit line is calculated, engineers must determine how well the model actually fits the original data. In addition to SSE, there are several conventional statistical measures used to evaluate this fit.

### Sum of Squares Total (SST)
SST measures the variability in the actual data by comparing each measured data point to the mean of all measured y-values. It is calculated by squaring these differences and summing them together:

$$SST = \sum (y_i - \overline{y})^2$$

Where:
* $y_i$ = the actual, measured dependent variable data point
* $\overline{y}$ = the mean of all actual y-values

If SST is small, the data points do not deviate much from the mean. If SST is large, the data deviate a lot from the mean.

### Coefficient of Determination ($r^2$)
The coefficient of determination, $r^2$, measures the percentage of variability in the data that can be explained by the linear model. It is calculated using the relationship between the sum of squared errors (SSE) and the sum of squares total (SST):

$$r^2 = 1 - \frac{\text{SSE}}{\text{SST}}$$

The value of $r^2$ always ranges from 0 to 1. A value closer to 1 indicates that the model line fits the data well. A small $r^2$ value only means the model does not explain the variance; it does not necessarily indicate a small amount of error. SSE is the appropriate measure for the amount of error.

#### Example Interpretation
If the engineer calculating the pen spring data finds an SSE of 1 and an SST of 4, the $R^2$ value is calculated as $1 - (1/4) = 0.75$. This means the linear model explains 75% of the variation in the collected spring data.

### Correlation Coefficient ($r$)
The correlation coefficient, $r$, measures the strength and direction of the linear relationship between the independent and dependent variables. It is calculated by taking the square root of $r^2$. 

The value of $r$ ranges from -1 to 1. A value close to 0 means there is very little correlation between the variables, while the strength of the relationship increases as the value moves closer to either 1 or -1.

* **Positive $r$:** Indicates a direct relationship (positive slope). An increase in the independent variable ($x$) tends to result in an increase in the dependent variable ($y$).
* **Negative $r$:** Indicates an indirect relationship (negative slope). An increase in the independent variable ($x$) tends to result in a decrease in the dependent variable ($y$).

## Calculating Regression in Excel
When evaluating bivariate data, you can use built-in Excel formulas or charting tools to quickly calculate the best-fit line and correlation values.

### Excel Functions
Excel requires the known y-values to be selected before the known x-values. 
* **Finding the Slope ($m$):** To calculate the slope, use the syntax `=SLOPE(known_y_values, known_x_values)`.
* **Finding the Y-Intercept ($b$):**  To calculate the y-intercept, use the syntax `=INTERCEPT(known_y_values, known_x_values)`.

### Excel Trendlines
Excel can also calculate the regression equation visually using a chart.
1. Highlight your data columns and insert a 2D line or scatter chart.
2. Right-click the data line on the generated chart and select **Add Trendline**.
3. Select the **Linear** option from the trendline menu.
4. Scroll down the menu and check the boxes for **Display Equation on chart** and **Display R-squared value on chart**.

To calculate the correlation coefficient ($r$) directly from the chart, simply take the square root of the displayed $r^2$ value using the formula `=SQRT(chart_r_squared_value)`. 

### Data Visualization Standards
When presenting regression models visually, engineers must follow standard formatting rules. Clear charts ensure the audience understands the physical context of the data and the modeling decisions made.

Follow these standards when creating your plots:
* **Chart Titles:** Include a descriptive title explaining the specific relationship being modeled.
* **Axis Labels:** Label both the x-axis and y-axis with the variable name and its corresponding units.
* **Raw Data:** Represent actual collected data points using individual markers (a scatter plot). Do not connect raw data points with a line.
* **Regression Models:** Represent the calculated best-fit model using a continuous line (a trendline) to clearly distinguish it from the measured data.

## Limitations, Interpolation, and Extrapolation
Models are only valid within the range of the collected data. When using a calculated regression line to make predictions, engineers must understand the difference between two key methods:

- **Interpolation:** The process of predicting or estimating a value that falls **within the bounds of your existing, measured data**.
- **Extrapolation:** The process of predicting outcomes by using a regression relationship **beyond the range of data used to create it**.

Care must be taken when extrapolating a regression relationship beyond the measured values. For the pen spring, Hooke's Law only applies within a specific linear range. If a spring is stretched beyond its physical limit until it deforms or fails, the relationship becomes non-linear. The calculated linear model cannot describe the behavior of a broken spring. For this reason, any use of extrapolation must always be accompanied by a clear engineering rationale.
