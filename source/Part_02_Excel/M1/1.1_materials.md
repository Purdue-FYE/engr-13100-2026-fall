## Writing Formulas in Excel
In Excel, an equation that performs mathematical calculations on worksheet values is called a formula.

All formulas in Excel begin with an equals sign `=`. For example, `=A2*B2` would multiply the values in cells A2 and B2.

### Operators in Excel
Excel uses mathematical operators inside formulas. 

| Operation | Operator | Example | 
| ------ | ------ | ------ | 
| Addition | `+` | `=A1+B1` | 
| Subtraction | `-` | `=A1-B1` | 
| Multiplication | `*` | `=A1*B1` | 
| Division | `/` | `=A1/B1` | 
| Exponent (Power) | `^` | `=A1^B1` | 

### Order of Operations
Excel follows standard order of operations:
1. Parentheses
2. Exponents
3. Multiplication and Division (Left to Right)
4. Addition and Subtraction (Left to Right)

### Cell References
When writing formulas, Excel refers to other cells using **cell addresses**. Examples: `A1`, `B4`, or `D12`

#### Relative Reference
A **relative reference** changes when you copy a formula to another cell. 

Example:
If `=A2+B2` is copied down one row, it becomes `=A3+B3`. 

#### Absolute References
An **absolute reference** stays fixed when copied. To create an absolute reference, use the `$` symbol in front of the column letter and row number. 

Example: 
If `=$A$2+B2` is copied down one row, it becomes `=$A$2+B3`.

Absolute references are used when you need to lock a constant value, such as a tax rate or conversion factor.

#### Mixed References
A **mixed reference** locks either the row or the column of a cell reference, but not both. Mixed references use the `$` symbol in front of either the column letter or the row number. 

Example:
- `$A1` - column A is locked, but the row will change when copied
- `A$1` - row 1 is locked, but the column will change when copied

Mixed references are useful when copying a formula across rows and columns, where one dimension (row or column) must remain constant while the other adjusts automatically.

```{admonition} Shortcut
:class: info
Press F4 (Windows) or Fn + F4 (Mac) while editing a cell reference to toggle between relative, mixed, and absolute references.
```

### Built-in Functions in Excel
A **function** is a pre-determined formula built into Excel that performs a common calculation.

Functions help you perform calculations efficiently and accurately without rewriting complex formulas.

All functions: 
- Begin with `=`
- Include parentheses `()`
- Take inputs called arguments

For example, `=SUM(A1:A5)` calculates the total of the values in cells A1 through A5.

#### Common Functions to Know

- `=SUM()` : calculates the total value of a range
- `=COUNT()` : returns the number of cells in a range that contain numeric data only
- `=MIN()` : finds the smallest value in a range
- `=MAX()` : finds the largest value in a range
- `=AVERAGE()` : calculates the mean of a range of values 
- `=MEDIAN()` : finds the middle value in a group of numbers
- `=MODE.SNGL()` : returns a single most frequent value
- `=MODE.MULT()` : returns multiple values if there is more than one mode

In ENGR 131, you are expected to select appropriate built-in functions rather than manually calculating statistics.

#### Additional Built-In Functions

Excel includes many additional built-in functions beyond basic statistics. These allow you to perform more advanced engineering calculations efficiently.

In the accompanying video, you will see examples of:
- Unit conversions using `=CONVERT()`
- Trigonometric functions such as `=SIN()`, `=COS()`, and `=TAN()`
- Converting between degrees and radians using `=RADIANS()` and `=DEGREES()`

These tools are especially useful when modeling physical systems, working with angles, or converting between measurement units.
