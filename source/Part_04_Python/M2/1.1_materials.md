### Sequential Execution

This is the default mode of execution where statements are executed line by line.

### Conditional Statements

These are used to execute a block of code based on a condition.

  - {python}`if` - executes a block of code if the condition is {python}`True`

  - {python}`if-else` - executes a block of code if the condition is {python}`True`, otherwise executes another block of code

  - {python}`if-elif-else` - executes a block of code if the condition is {python}`True`, otherwise checks another condition

  - nested {python}`if` - {python}`if` statement inside another {python}`if` statement

### Looping Statements

These are used to execute a block of code repeatedly.

  - {python}`for` - iterates over a sequence of items

  - {python}`while` - executes a block of code as long as the condition is {python}`True`

### Control Statements

These are used to control the flow of execution in a program.

  - {python}`break` - exits the loop

  - {python}`continue` - skips the current iteration

  - {python}`pass` - does nothing

  - {python}`return` - exits the function

  - {python}`assert` - raises an exception if a condition is {python}`False`

  - {python}`raise` - raises an exception

## CONDITIONAL STRUCTURES

Conditional Structures, also known as selection structures or decision structures.

**Keywords** : {python}`if`, {python}`elif`, {python}`else `

### Single alternative example:

Write a program that prints a warning message if the temperature is greater than 30 degrees Celsius.

  ```python
  temperature = int(input("Enter the temperature: "))
  if temperature > 30:
      print("It's hot outside")
  print("End of program")
  ```

### Dual alternative example:

Write a program that prints a warning message if the temperature is greater than 30 degrees Celsius, otherwise print a message that it's a nice day.

  ```python
  temperature = int(input("Enter the temperature: "))

  if temperature > 30:
      print("It's hot outside")
  else:
      print("It's a nice day")
  print("End of program")
  ```

### Multiple alternative example:

Write a program that prints a warning message if the temperature is greater than
30 degrees Celsius, a message that it's a nice day if the temperature is between
20 and 30 degrees Celsius, and a message that it's cold outside if the
temperature is less than 20 degrees Celsius.

  ```python
  temperature = int(input("Enter the temperature: "))
  if temperature > 30:
      print("It's hot outside")
  elif temperature >= 20 and temperature <= 30:
      print("It's a nice day")
  else:
      print("It's cold outside")
  print("End of program")
  ```

### Nested example:

Write a program that prints a warning message if the temperature is greater than
30 degrees Celsius and the humidity is greater than 50%, otherwise print a
message that it's a nice day.

  ```python
  temperature = int(input("Enter the temperature: "))
  humidity = int(input("Enter the humidity: "))
  if temperature > 30:
      if humidity > 50:
          print("It's hot and humid")
      else:
          print("It's hot but not humid")
  else:
      print("It's a nice day")
  print("End of program")
  ```

Functions are reusable code blocks that perform a specific task.

Types of functions:

  - Built-in functions - functions that are built into Python

  - User-defined functions - functions defined by the user

### Built-in functions

Examples: {python}`print()`, {python}`range()`, {python}`input()` etc

### User defined functions

- {python}`def` keyword is used to define a function

- Function names should be descriptive and meaningful
  (follows the same rules as variable names)

- A function call is required to execute the function

- Functions can be called multiple times

- Functions can be defined inside another function

### Function Arguments and Parameters:
- Arguments are values passed to a function

- Parameters are variables used to define a function and are optional

- Arguments are assigned to parameters based on their position

- Arguments can be passed as positional arguments or keyword arguments

- Default parameters are used when no argument is passed

```{table} Positional and Keyword Arguments
:name: tab:Py:M2:pre_class_materials_arguments

| **Positional arguments** | **Keyword arguments** |
|:-------------------------|:----------------------|
| Arguments passed to a function based on their position | Arguments passed to a function based on their name |
| Order of arguments is important | Order of arguments is not important |
| Number of arguments should match the number of parameters | Number of arguments should match the number of parameters |
```

```{admonition} Note
:class: note 

- All positional arguments must be placed before keyword arguments

- The argument variable name and the parameter variable name do not have to match, just the positional order matters
```

**Default parameters**

- Default parameters are used when no argument is passed

- Default parameters should be at the end

### Return statement

- The {python}`return` statement is used to return a value from a function

- The {python}`return` statement is optional

- The {python}`return` statement can return multiple values

- The {python}`return` statement can be used to exit a function

- No other statement is executed after the return statement in a function

### Benefits of using functions:

- Code reusability

- Modularity

- Easy debugging and maintenance

- Better readability, organization, and efficiency

### Function recursion: (not covered in this course)

  - Recursion is a technique in which a function calls itself

  - Base case is required to prevent infinite recursion

  - Recursion is used to solve complex problems and simplify code

- Scope is the region of the program where a variable is recognized

- Scope determines the visibility of a variable

- Scope can be local or global

    - Local scope - variables declared inside a function are local variables and can only be accessed inside that function

    - Global scope - variables declared outside a function are global variables and can be accessed throughout the program

- Avoid using global variables as they can be modified from anywhere in the program and can lead to bugs

- Use local variables instead to avoid conflicts and bugs in the program

- Use the global keyword to modify a global variable inside a function

- Known constants are acceptable to use as global variables such as gravity (g = 9.81) in physics calculations.

Flowcharts are visual planning tools that help you map the logic of a program before writing code.

They are useful for:

- Breaking a problem into clear, logical steps

- Identifying decision points ({python}`if`, {python}`elif`, {python}`else`)

- Tracing repeated actions ({python}`for` and {python}`while` loops)

- Communicating program logic with teammates

### Flowchart example

Example problem: Ask the user for a number and print whether it is even or odd.

```{mermaid}
flowchart TD
    A([Start]) --> B[/Input number n/]
  B --> C{Is n even?}
  C -->|Yes| D[Print Even]
  C -->|No| E[Print Odd]
    D --> F([End])
    E --> F
```

### Tips for creating coding flowcharts

- Start with the main goal of the program, then add major steps first.

- Write decision questions so they can be answered clearly with Yes/No.

- Label decision branches consistently (for example, Yes on the left and No on the right).

- Keep each process box to one action to make conversion to code easier.

- After finishing the flowchart, trace one sample input through it before coding.
