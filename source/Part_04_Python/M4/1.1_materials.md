```python
# 2    29

```

### Combining DataFrames

The `pd.merge()` function joins pandas DataFrames on a common column, matching rows where the values are equal.

```python
import pandas as pd

df1 = pd.DataFrame({
    "ID": [1, 2, 3],
    "Name": ["Alice", "Bob", "Charlie"]
})

df2 = pd.DataFrame({
    "ID": [1, 2, 3],
    "Score": [85, 92, 78]
})

# Combine on the shared "ID" column
combined = pd.merge(df1, df2, on="ID")

print(combined)
# Output
#    ID     Name  Score
# 0   1    Alice     85
# 1   2      Bob     92
# 2   3  Charlie     78
```

### Grouping and Aggregating Data

Grouping data allows users to calculate statistics for categories within a dataset.

```python
import pandas as pd
import numpy as np

# Made-up speed data for 3 roadways
data = {
        "Road": ["Main St",   "Highway 1", "Ring Road", "Highway 1",
            "Ring Road", "Main St",   "Highway 1", "Ring Road",
            "Main St",   "Highway 1", "Ring Road", "Main St"],
        "Speed": [65, 72, 68, 70,
                35, 28, 42, 31,
                55, 60, 58, 62]
}

df = pd.DataFrame(data)

# Calculate average speed by roadway
avg_speed = df.groupby("Road")["Speed"].mean()

print(avg_speed)
# Output:
# Road
# Highway 1    68.75
# Main St      34.00
# Ring Road    58.75
# Name: Speed, dtype: float64
```

### Creating a Scatter Plot

Scatter plots are useful for displaying relationships between variables. The default marker shape for scatter plots is a circle, but there are many built-in data marker shapes in Matplotlib to choose from. Data markers are used for both scatter and line plots (see examples of line plots with markers below).

| Marker code | Shape | Common use case |
|---|---|---|
| `"o"` | Circle | General data points |
| `"s"` | Square | Categorical groups |
| `"^"` | Triangle up | Positive deviation |
| `"v"` | Triangle down | Negative deviation |
| `"D"` | Diamond | Highlighted outliers |
| `"d"` | Thin diamond | Dense scatter plots |
| `"+"` | Plus | Overlay markers |
| `"x"` | Cross | Excluded/invalid points |
| `"*"` | Star | Special points of interest |
| `"p"` | Pentagon | Multi-class datasets |
| `"h"` | Hexagon | Binned data |
| `"."` | Point | Large datasets (minimal ink) |

You pass these directly to the marker parameter:

```python
plt.scatter(x, y, marker="^")
```

```python
import matplotlib.pyplot as plt

# Example data
speed = [25, 35, 45, 55, 65]
stopping_distance = [12, 18, 29, 40, 55]

# Create a scatter plot
plt.scatter(speed, stopping_distance)

# Add labels and title
plt.xlabel("Speed (mph)")
plt.ylabel("Stopping Distance (ft)")
plt.title("Stopping Distance vs. Speed")

# Apply tight layout to prevent label clipping
plt.tight_layout()

# Display the graph
plt.show()
```

### Plotting Multiple Data Sets with Two Y-Axes

Sometimes engineers need to compare two variables that use different units or scales. In these cases, a graph can use two y-axes.

The example below compares machine temperature and power consumption during operation.

```python
import matplotlib.pyplot as plt

# Example data
time = [0, 5, 10, 15, 20, 25]

temperature = [68, 72, 78, 85, 88, 90]
power = [120, 135, 150, 165, 180, 190]

# Create figure and first axis
fig, ax1 = plt.subplots(figsize=(10, 6))

# Plot temperature data as a red line plot with circle data markers
ax1.plot(time, temperature, marker='o', color='red')

# Label first y-axis
ax1.set_xlabel("Time (minutes)", fontsize=12)
ax1.set_ylabel("Temperature (C)", fontsize=12)

# Increase size of axis tick labels
ax1.tick_params(axis="both", labelsize=12)

# Create second y-axis
ax2 = ax1.twinx()

# Plot power data as a blue line plot with data markers
ax2.plot(time, power, marker='s', color='blue')

# Label second y-axis
ax2.set_ylabel("Power Consumption (W)", fontsize=12)

# Increase size of axis tick labels
ax2.tick_params(axis="both", labelsize=12)

# Add title
plt.title("Machine Temperature and Power Consumption", fontsize=14)

plt.tight_layout()
plt.show()
```

![Line chart titled “Machine Temperature and Power Consumption” showing two upward trends over time. The x-axis represents time in minutes (0, 5, 10, 15, 20, 25). The left y-axis shows temperature in °C, increasing from about 68°C at 0 minutes to 90°C at 25 minutes (blue line with square markers). The right y-axis shows power consumption in watts, rising from about 120 W to 190 W over the same period (red line with circular markers). Both temperature and power steadily increase as time progresses, with a sharper rise between 10 and 15 minutes.](/Part_04_Python/M4/materials/multiple_y_axis_plot.png)

```{table} Commonly Used Methods
| Method     | Description                                                                                                                               |

| .suffix    | Can be used to access the extension from a path.                                                                                          |
```

```python
from pathlib import Path
```

- You can check whether a directory exists and whether it is a folder:
   ```python
   from pathlib import Path

   else:
      print(f"{directory} does not exist.")
   ```
