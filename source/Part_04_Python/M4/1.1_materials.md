### Strings as sequences of characters

A string is a sequence of characters. In Python, strings are immutable sequences
of Unicode code points.

### String literals

A string literal is a sequence of characters enclosed in single quotes ('...')
or double quotes ("...").

### String manipulation as an immutable sequence

For strings x and y with indices i, j and k, the following operations are supported:

- Indexing : {python}`x[i]`, {python}`x[-i]`

- Slicing : {python}`x[i:j]`, {python}`x[i:j:k] # start, stop, step`

- Concatenation : {python}`x + y`

- Repetition : {python}`n * x`, where n is an integer

- Membership test : {python}`x in y`, {python}`x not in y`

- Length : {python}`len(x)`, {python}`min(x)`, {python}`max(x)`

- Iteration : {python}`for i in x`

- Comparison : {python}`x == y`, {python}`x != y`, {python}`x < y`, {python}`x <= y`, {python}`x > y`, {python}`x >= y`

- Searching : {python}`x.find(y)`, {python}`x.rfind(y)`, {python}`x.index(y)`, {python}`x.rindex(y)`

- Counting : {python}`x.count(y)`

- Ordering : {python}`sorted(x)`, {python}`reversed(x)`

### String methods

For strings x and y, the following methods are supported:

```python
- x.lower()      # lowers the case of all characters
- x.upper()      # uppercases all characters
- x.title()      # capitalizes the first character of each word
- x.capitalize() # capitalizes the first character of the string
- x.split()      # splits a string into a list of substrings
- x.strip()      # removes leading and trailing whitespace (lstrip, rstrip)
- x.replace()    # replaces a substring with another substring (old, new)
- x.join()       # joins a list of substrings into a single string
- x.startswith() # checks if a string starts with a specified prefix (prefix, start, end)
- x.endswith()   # checks if a string ends with a specified suffix
- x.isalpha()    # checks if all characters are alphabetic, returns Boolean
- x.isdigit()    # checks if all characters are digits, returns Boolean
- x.isalnum()    # checks if all characters are alphanumeric, returns Boolean
- x.islower()    # checks if all characters are lowercase, returns Boolean
- x.isupper()    # checks if all characters are uppercase, returns Boolean
- x.isspace()    # checks if all characters are whitespace, returns Boolean
```

### File Input

#### {python}`open()` function

Opens a file and returns a file object.

Syntax: {python}`open(file, mode)`

Example: {python}`f = open("hail_purdue.txt", "r")`

   - read mode (default) - "r"

   - write mode - "w"

   - append mode - "a"

   - binary mode - "b"

   - read/write mode - "r+"

   - read/write binary mode - "rb+"

   - read/write append mode - "a+"

   - read/write append binary mode - "ab+"

#### {python}`close()` function

Closes the file. Must be called after the file is opened.

Syntax: {python}`f.close()`

#### {python}`with` statement

automatically closes the file

Syntax:

```python
with open(file, mode) as f:
   # code block
```

## {python}`pathlib`

The {python}`pathlib` package provides a convenient way to handle file paths and directories using methods and attributes tailored for path manipulations.

Here is the link to the [{program}`Python` Official Documentation on {python}`pathlib`](https://docs.python.org/3/library/pathlib.html#basic-use)

{python}`pathlib` is a built-in {program}`Python` library that provides an object-oriented approach to working with filesystem paths. It allows you to easily manipulate, traverse, and interact with directories (a.k.a. folders) and files.

### Commonly Used {python}`pathlib` Methods
```{table} Commonly Used Methods
| Method     | Description                                                                                                                               |
|------------|-------------------------------------------------------------------------------------------------------------------------------------------|
| .iterdir() | Can iterate over files and directories in the given path. This makes it easy to check file extensions and process each file individually. |
| .name      | Can be used to access the filename.                                                                                                       |
| .suffix    | Can be used to access the extension from a path.                                                                                          |
```
### Using {python}`pathlib`

Since {python}`pathlib` is included in Python 3.4 and later, so no pip installation is required. You can simply import it as follows:

```python
from pathlib import Path
```

### Exploring Directories:

- You can check whether a directory exists and whether it is a folder:
   ```python
   from pathlib import Path

   directory = Path("dataset")  # Replace with your actual directory path

   if directory.exists() and directory.is_dir():
      print(f"{directory} exists and is a folder.")
   else:
      print(f"{directory} does not exist.")
   ```

- You can list all files and subdirectories in a given directory:
   ```python
   for item in directory.iterdir():
      print(item)  # Prints each file or folder within the directory
   ```

### Viewing Files and their Extensions:

- You can filter files by their extensions (such as .png or .jpg):
   ```python
   # Find all CSV files in the directory
   csv_files = list(directory.glob("*.csv"))
   print("CSV Files:", csv_files)

   # Find all PNG and JPG image files in the directory
   image_files = list(directory.glob("*.png")) + list(directory.glob("*.jpg"))
   print("Image Files:", image_files)
   ```

{python}`matplotlib` is a plotting library for the {program}`Python` programming language and its numerical mathematics extension NumPy.

### Installing {python}`matplotlib`

Enter the following command in the terminal:

```python
python3 -m pip install matplotlib
```

### Basic Plotting:

- The most basic plot is the line plot.

- A line plot is created by specifying the {python}`x` and {python}`y` values of the data points you want to plot and then calling the {python}`plot()` function.

- The {python}`plot()` function takes the {python}`x` and {python}`y` values as arguments and creates a line plot.

- The {python}`show()` function is used to display the plot.

- The {python}`set_title()`, {python}`set_xlabel()`, and {python}`set_ylabel()` functions are used to set the title, x-axis label, and y-axis label of the plot, respectively.

- The {python}`savefig()` function is used to save the plot as an image file.

#### Types of Plots

- {python}`matplotlib` provides a variety of plots that can be used to visualize data.

- Some commonly used plots are: Line Plot, Scatter Plot, Bar Plot, Histogram, Pie Chart, Box Plot, Heatmap, etc.

#### Customizing Plots

- {python}`matplotlib` allows you to customize the appearance of the plots by setting various properties such as the color, line style, marker style, etc.

- You can also add labels, titles, legends, and annotations to the plots.

#### Multiple Plots

- You can create multiple plots in the same figure by using the {python}`subplots()` function.

- The first two arguments to the {python}`subplots()` function are the number of rows and the number of columns

- Example:
   ```python
   fig, ax = plt.subplots(2, 1)

   ax[0].plot(x, y1)

   ax[1].plot(x, y2)
   ```

- The {python}`tight_layout()` function is used to adjust the spacing between the plots.
