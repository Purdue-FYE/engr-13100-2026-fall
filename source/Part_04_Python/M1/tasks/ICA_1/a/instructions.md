## Background

ENGR 131 students submit their Python assignments to Gradescope and their submissions are automatically graded. Students get instant feedback on their assignments with this auto grader!

The purpose of this in-class activity is to teach students about common auto grader errors that occur after assignment submission.

## Files Needed

Download the Python file {download}`hello_user.py </Part_04_Python/M1/in-class/ICA_1/hello_user.py>`.

## Activity Instructions & Submission

1. Download the python file 'hello_user.py' and run the script in VS Code. Use the sample output below to make sure your code displays the correct output.
2. Submit your python file to [INSERT ASSIGNMENT NAME] on Gradescope.
3. Wait for the auto grader to finish grading your submission, then read the auto grader feedback. The feedback should have two errors displayed in red text:

- **Incorrect file name**: the name of your submitted file should match the file name expected by the auto grader.
- **Incorrect output spacing**: the output produced by your code should match the output expected by the auto grader.

4. Use the auto grader feedback, the information above, and the sample output below to correct these submission errors.
5. Resubmit your python file to [INSERT ASSIGNMENT NAME] on Gradescope to determine if the submission errors were corrected.

*If submission errors persist, repeat steps 4 and 5 until all errors are resolved.*
