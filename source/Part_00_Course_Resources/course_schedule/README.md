# Course Schedule Files

This folder contains source inputs for the course schedule plus helper scripts.

## Quick Rules

- Edit `schedule_assignments.csv` for assignment dates, points, names, and manual rows.
- Edit `schedule_topics.csv` for class-topic order.
- Do not edit files under `source/_build/...`; those are generated temporary artifacts.
- You can run schedule generation safely without losing manual schedule edits. 

## File Guide

### `schedule_assignments.csv`

User-maintained assignment schedule table.

Use this file to:
- set `class_slot` and `due_date`
- adjust `points`, `name`, or `type`
- add manual-only rows (for items not discovered from TOC/task pages)

This file is the manual source of truth and supersedes generated defaults.

### `schedule_topics.csv`

Ordered list of class topics used by the HTML schedule builder.

### `assignment_overrides.csv` (deprecated)

Deprecated and ignored by the current generator pipeline.

Do not use this file for new edits. Move any remaining values into `schedule_assignments.csv`.

### `generate_schedule_assignments.py`

Builds temporary assignment CSV artifacts from TOC + task pages, then merges with manual schedule edits.

Outputs:
- `source/_build/intermediate/course_schedule/schedule_assignments.generated.csv`
- `source/_build/intermediate/course_schedule/schedule_assignments.merged.csv`

Merge precedence:
- manual `schedule_assignments.csv` values override generated values by `assignment_id`
- manual-only `assignment_id` rows are appended

### `student_course_schedule.html`

Rendered schedule HTML included in the published course page.

Usually regenerated by script; not typically edited by hand.

### `schedule_assignments.generated.csv` (legacy in this folder)

If present in this directory, treat it as legacy/stale output from an older workflow.

Current generated artifacts are written to `source/_build/intermediate/course_schedule/`.

## Typical Workflow

1. Edit `schedule_topics.csv` and/or `schedule_assignments.csv`.
2. Run: `make schedule` to run the generator and publish the schedule to the site

OR

```bash
python3 source/Part_00_Course_Resources/generate_schedule.py
```
to generate the schedule. 

3. Verify updated HTML in `student_course_schedule.html`.

## Related Scripts

- `source/Part_00_Course_Resources/generate_schedule.py`
  - regenerates assignment build artifacts
  - reads merged assignments CSV from `_build`
  - writes `student_course_schedule.html`
- `source/generate_assignment_mapping.py`
  - uses the same merged assignment logic for grader mapping consistency
