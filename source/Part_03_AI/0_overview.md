# AI in Engineering


```{rubric} Topics Covered
```
- Evolution of computing hardware, data storage, and binary encoding
- Logic gates, binary arithmetic, and simulating logic in Excel
- Definition of artificial intelligence (Strong vs. Weak AI)
- Categories of AI models (Rule-based and Machine Learning: Prediction, Discriminative, Generative)
- Decision tree algorithms, computational limits, and optimization strategies
- Neural network architecture (input, hidden, and output layers)
- Calculating neuron activations using weights, biases, and logistic functions
- Training models via cost functions, gradients, and backpropagation

```{rubric} Skills and Learning Objectives
```

At the end of this module, you will be able to:

- Manage, format, and correctly submit local digital files to Gradescope.
- Explain how computers store data and process calculations physically using transistors and logic gates.
- Simulate physical hardware logic using built-in spreadsheet operators.
- Differentiate between actual human intelligence and the algorithmic models used to simulate intelligence in modern AI.
- Evaluate how algorithms like decision trees use optimization to mitigate complex problem constraints.
- Describe the structural layers of a neural network and the mathematical principles of neuron activation.
- Explain how neural networks autonomously learn by utilizing cost functions and backpropagation to recalibrate parameters.
