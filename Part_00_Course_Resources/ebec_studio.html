FYE-EBEC Undergraduate Coding and Debugging Studio#

The FYE-EBEC Undergraduate Coding and Debugging Studio is a computer lab where coding coaches help engineering students plan, write, and debug code. Use the studio for help with the programming work in ENGR 131.

Location and Hours#

The studio is in Dudley and Lambertus Hall, room 3123 (DUDL 3123), on the third floor next to the main staircase.

Table 1 FYE-EBEC Studio hours, Fall 2026#

Days

Hours

8:00 AM to 4:00 PM

The studio is closed on the following dates:

  • Monday, September 7, 2026 (Labor Day)

  • Monday, October 12 and Tuesday, October 13, 2026 (Fall Break)

  • Wednesday, November 25 through Saturday, November 28, 2026 (Thanksgiving Break)

The FYE-EBEC Coding and Debugging Studio website lists current hours and closures.

Evening and Weekend Help

The studio is open during the day on weekdays. For help in the evening or on Sunday, attend the ENGR 131 GTA help sessions.

What the Studio Offers#

  • Planning a solution before you write code, using pseudocode, flowcharts, drawings, recipes, or hand-written algorithms

  • Debugging code that does not run or does not produce the correct result

  • Finding reliable online resources for a programming problem

  • A place to work on homework, meet with your team, and practice programming concepts

  • Explanations of the programming concepts from class, from a student perspective

What the Studio Does Not Offer#

  • Solutions to homework problems

  • Help with take-home exams

  • Help with course concepts outside of programming

  • Grade changes or answers to administrative questions about a course

Contact your GTA or instructor with questions about your grade.

Attempt the Problem First

Coaches help with homework and projects only after you have made an honest attempt at a solution. Work on the programming problem on your own before your visit.

Get Help in the Studio#

  1. Find an open seat in the lab.

  2. Scan the QR code on the table near you and enter your station number to sign in.

  3. Open the instructions, code, and any error messages for the problem you need help with.

  4. Stay at your station. A coding coach will come to you as soon as possible.

  5. Before you leave, complete the studio satisfaction survey. The survey is also available by QR code in the lab.

Represent the Problem Before You Code#

A representation of a problem is a plan for its solution, written before the code. Flowcharts, pseudocode, algorithms, recipes, and drawings are all representations. Bring any representation you have to the studio.

Writing a representation first:

  • Helps you think through the problem and a possible solution

  • Exposes errors in the algorithm before any code exists

  • Gives a step-by-step procedure for writing the code, which reduces typing and logic errors

  • Communicates the intent of your code to someone else, such as a coding coach, who can then help find what is wrong
